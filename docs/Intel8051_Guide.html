Intel 8051 Programming Guide

Platform: Intel 8051  |  Architecture: 8-bit CISC  |  Clock: 12 MHz  |  I/O: 4 Ports (32 pins)

1. Architecture Overview

  • Data Bus: 8-bit
  • Address Bus: 16-bit (64KB code space + 256B internal RAM + 64KB external data space)
  • Clock: 12 MHz (12 clock cycles per machine cycle)
  • Internal RAM: 128 bytes (direct) + 128 bytes (indirect upper half)
  • Special Function Registers (SFRs): Mapped at addresses 0x80-0xFF
  • I/O Ports: 4 quasi-bidirectional ports (P0-P3, 8 pins each = 32 pins)
  • Timers: Timer 0 and Timer 1 (16-bit)
  • Serial: Full-duplex UART (SCON/SBUF)
  • Interrupts: 5 sources (INT0, INT1, Timer0, Timer1, Serial)

2. Quick Start

Open ArduSim, select Intel 8051 from the board selector, and write assembly in the editor:

; Blink LED on P1.0
        MOV A, #01H        ; A = 0x01
        MOV P1, A          ; P1 = 0x01 (LED ON)
        SJMP $              ; Infinite loop

Press Run. The LED on P1.0 will turn on.

4. Memory Map

Internal RAM (256 bytes):
  0x00 - 0x07 : Register Bank 0 (R0-R7) [default]
  0x08 - 0x0F : Register Bank 1
  0x10 - 0x17 : Register Bank 2
  0x18 - 0x1F : Register Bank 3
  0x20 - 0x2F : Bit-addressable area (128 bits)
  0x30 - 0x7F : General purpose RAM
  0x80 - 0xFF : SFR space (direct addressing only)

External Data Memory: 0x0000 - 0xFFFF (64KB, accessed via MOVX)
Code Memory:          0x0000 - 0xFFFF (64KB, accessed via MOVC)

5. I/O Ports

; Write to Port 1
MOV P1, #0FFH       ; All pins HIGH
MOV P1, #00H        ; All pins LOW

; Read from Port 1
MOV A, P1           ; Read P1 into A

; Bit-level operations
SETB P1.0           ; Set P1.0 = 1
CLR P1.0            ; Clear P1.0 = 0
CPL P1.0            ; Toggle P1.0
JB P1.0, label      ; Jump if P1.0 is set
JNB P1.0, label     ; Jump if P1.0 is not set

; Setup Timer 0 in Mode 1 (16-bit)
MOV TMOD, #01H      ; Timer 0, Mode 1
MOV TH0, #03CH      ; Load count for ~50ms at 12MHz
MOV TL0, #0B0H
SETB TR0            ; Start Timer 0

; Serial: Mode 1, 9600 baud
MOV SCON, #50H      ; Serial Mode 1, REN=1
MOV TMOD, #20H      ; Timer 1, Mode 2 (auto-reload)
MOV TH1, #0FDH      ; 9600 baud at 12MHz
SETB TR1            ; Start Timer 1
MOV SBUF, #'A'      ; Transmit 'A'

14. Complete Examples

Example 1: Blink LED on P1.0

        ORG 0000H
LOOP:   MOV P1, #01H     ; P1.0 = 1 (LED ON)
        ACALL DELAY       ; Wait
        MOV P1, #00H     ; P1.0 = 0 (LED OFF)
        ACALL DELAY
        SJMP LOOP         ; Repeat

; Delay subroutine (~250ms at 12MHz)
DELAY:  MOV R3, #250
D1:     MOV R4, #250
D2:     MOV R5, #250
D3:     DJNZ R5, D3
        DJNZ R4, D2
        DJNZ R3, D1
        RET

Example 2: Add Two Numbers

        ORG 0000H
        MOV A, #25H       ; A = 0x25 (37)
        MOV R0, #1AH      ; R0 = 0x1A (26)
        ADD A, R0          ; A = A + R0 = 0x3F (63)
        MOV 30H, A        ; Store result at 0x30
        SJMP $

Example 3: Count on Port 1

        ORG 0000H
        MOV A, #00H       ; Start at 0
LOOP:   MOV P1, A         ; Output to P1
        ACALL DELAY
        INC A              ; A = A + 1
        SJMP LOOP

DELAY:  MOV R3, #250
D1:     MOV R4, #250
D2:     DJNZ R4, D2
        DJNZ R3, D1
        RET

Example 4: Serial Output "HELLO"

        ORG 0000H
        MOV SCON, #50H    ; Serial Mode 1
        MOV TMOD, #20H    ; Timer 1 Mode 2
        MOV TH1, #0FDH    ; 9600 baud
        SETB TR1           ; Start timer

        MOV SBUF, #'H'
        ACALL WAIT_TI
        MOV SBUF, #'E'
        ACALL WAIT_TI
        MOV SBUF, '#0LL'
        ACALL WAIT_TI
        MOV SBUF, '#0LL'
        ACALL WAIT_TI
        MOV SBUF, #'O'
        SJMP $

WAIT_TI: JNB TI, WAIT_TI  ; Wait for TX complete
         CLR TI             ; Clear flag
         RET

Example 5: Read Buttons on P0, Display on P1

        ORG 0000H
LOOP:   MOV A, P0         ; Read P0 (buttons)
        MOV P1, A         ; Display on P1 (LEDs)
        SJMP LOOP

15. Tips and Gotchas

Tip: Use ORG 0000H at the start. The 8051 begins execution at address 0x0000.
Tip: SJMP $ creates an infinite loop at the current address. Use it to halt execution.
Tip: The 8051 has 4 register banks. Use SETB RS0 / CLR RS0 etc. to switch banks and get 32 general-purpose registers.
Warning: P0 is open-drain and defaults to 0xFF. It needs external pull-up resistors. In the simulator, P0 works as quasi-bidirectional.
Warning: The SP initializes to 0x07, meaning the first PUSH goes to 0x08 (Bank 1 R0). If you use register banks 1-3, initialize SP to 0x2F or higher.
Note: Writing to SBUF (0x99) triggers serial output. The character appears in the serial monitor.
