Intel 8085 Programming Guide

Platform: Intel 8085  |  Architecture: 8-bit CISC  |  Clock: 3 MHz  |  Memory: 64KB

This guide covers how to write 8085 assembly language programs in the ArduSim simulator. The assembler supports the complete 8085 instruction set with standard Intel syntax.

1. Architecture Overview

  • Data Bus: 8-bit
  • Address Bus: 16-bit (64KB address space)
  • Clock: 3 MHz
  • Registers: 6 general-purpose 8-bit (B, C, D, E, H, L) + Accumulator + Flags
  • Register Pairs: BC, DE, HL (16-bit)
  • Special Registers: SP (Stack Pointer), PC (Program Counter)
  • I/O: 256 input ports + 256 output ports (separate I/O space)
  • Interrupts: TRAP, RST 7.5, RST 6.5, RST 5.5, INTR

2. Quick Start

Open ArduSim, select Intel 8085 from the board selector, and write assembly in the editor:

; Blink LED on Port A, bit 0
        MVI A, 01H        ; A = 0x01 (bit 0)
        OUT 00H           ; Output to Port A
        HLT               ; Stop

Press Run. The LED on PA0 will turn on.

4. Memory Map & I/O

Memory Space (64KB)

0x0000 - 0xFFFF : 64KB unified memory space
                   Program code goes here (loaded by assembler)
                   Data and stack also reside here

I/O Ports (256 ports)

PortPurpose
0x00Port A (PA0–PA7) — connected to board pins PA0–PA7
0x01Port B (PB0–PB7) — connected to board pins PB0–PB7
0x02Port C (PC0–PC7) — connected to board pins PC0–PC7
0xFFSerial output — writing a byte prints it to the serial monitor
Note: The 8085 uses separate I/O addressing. IN/OUT instructions access I/O ports, not memory. Memory-mapped operations use LDA/STA.

9. Stack & Subroutines

; Push register pair to stack
PUSH B          ; SP-=2, [SP]=C, [SP+1]=B
PUSH D          ; SP-=2, [SP]=E, [SP+1]=D
PUSH H          ; SP-=2, [SP]=L, [SP+1]=H

; Pop from stack
POP B           ; B=[SP+1], C=[SP], SP+=2
POP D
POP H

; Call and return
CALL SUBROUTINE ; Push PC, jump to SUBROUTINE
RET             ; Pop PC, return to caller

SUBROUTINE:
    ; ... subroutine code ...
    RET
Note: The stack grows downward. PUSH decrements SP, POP increments SP. Initialize SP before using the stack (e.g., LXI SP, 0FFF8H).

10. I/O Port Operations

; Output to port
MVI A, 0FFH     ; A = 0xFF (all bits high)
OUT 00H         ; Write to Port A (all PA pins HIGH)

; Input from port
IN 01H          ; Read Port B into A

; Serial output (port 0xFF)
MVI A, 'A'      ; A = 'A' (0x41)
OUT 0FFH        ; Print 'A' to serial monitor

12. Complete Examples

Example 1: Count from 1 to 10

        ORG 0000H
        MVI A, 00H        ; A = 0
LOOP:   INR A              ; A = A + 1
        CPI 0AH            ; Compare A with 10
        JNZ LOOP           ; If A != 10, repeat
        HLT                ; Stop (A = 10)

Example 2: Add Two Numbers

        ORG 0000H
        MVI A, 25H        ; A = 0x25 (37 decimal)
        MVI B, 1AH        ; B = 0x1A (26 decimal)
        ADD B              ; A = A + B = 0x3F (63 decimal)
        STA 2050H          ; Store result at memory location 2050H
        HLT

Example 3: Blink LED on Port A

        ORG 0000H
        MVI A, 01H        ; A = 0x01 (bit 0)
ON:     OUT 00H            ; Output to Port A (LED ON)
        MVI C, 0FFH        ; Delay counter
D1:     DCR C              ; Decrement counter
        JNZ D1             ; Loop until C=0
        MVI A, 00H        ; A = 0x00
        OUT 00H            ; Output to Port A (LED OFF)
        MVI C, 0FFH
D2:     DCR C
        JNZ D2
        JMP ON             ; Repeat forever

Example 4: Subroutine - Square of a Number

        ORG 0000H
        MVI A, 05H        ; Input: A = 5
        CALL SQUARE        ; A = A * A = 25
        HLT

; Subroutine: returns A = A * A
SQUARE: MOV B, A           ; B = A (save copy)
        MVI A, 00H        ; A = 0 (accumulator for result)
LOOP:   ADD B              ; A = A + B
        DCR B              ; B = B - 1
        JNZ LOOP           ; Repeat B times
        RET

Example 5: Serial Output - Print "HELLO"

        ORG 0000H
        MVI A, 'H'
        OUT 0FFH           ; Serial output
        MVI A, 'E'
        OUT 0FFH
        MVI A, 'L'
        OUT 0FFH
        MVI A, 'L'
        OUT 0FFH
        MVI A, 'O'
        OUT 0FFH
        HLT

13. Tips & Gotchas

Tip: Use ORG 0000H at the start of your program to set the loading address.
Tip: The M register is not a physical register — it refers to the memory location pointed to by the HL pair. Use MOV A, M to load from [HL], and MOV M, A to store to [HL].
Tip: Register pairs for LXI, PUSH, POP, DAD are: BC, DE, HL, SP. For LDAX/STAX the pairs are: BC, DE (HL not supported).
Warning: INR and DCR do NOT affect the Carry flag. Only AC, Z, S, P are updated.
Warning: The DAD instruction only affects the Carry flag. All other flags are unchanged.
Warning: Initialize SP before using CALL, PUSH, or POP. A common pattern: LXI SP, 0FFF8H.
