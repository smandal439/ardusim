STM32F746G-DISCO Programming Guide

Board: STM32F746G-DISCO Discovery  |  MCU: STM32F746NGH6 ARM Cortex-M7 216MHz  |  Logic: 3.3V

This guide covers how to write C code for the STM32F746 in the ArduSim simulator using HAL functions or direct register access.

1. Board Overview

The STM32F746G-DISCO Discovery board in ArduSim replicates the real STMicroelectronics Cortex-M7 MCU with:

  • MCU: ARM Cortex-M7, 216 MHz, 1 MB Flash, 340 KB SRAM
  • GPIO: 11 ports (A–K), each with up to 16 pins
  • Onboard LED: LD1 (PI1 / D13) — active high
  • User Button: B1 (PC13) — active low
  • ADC: 3 ADCs, 12-bit, 6 analog pins (A0–A5)
  • USART: USART1–6
  • SPI: SPI1–4
  • I2C: I2C1–3
  • Timers: TIM1–TIM14
  • Display: 4.3″ TFT LCD (ILI9341, 480×272)
  • Logic Level: 3.3V

2. Quick Start

Open ArduSim, select STM32F746G-DISCO from the board selector, and write code in the editor:

#include <stm32f7xx_hal.h>

int main() {
    __HAL_RCC_GPIOI_CLK_ENABLE();
    GPIO_InitTypeDef g = {0};
    g.Pin = GPIO_PIN_1;
    g.Mode = GPIO_MODE_OUTPUT_PP;
    g.Pull = GPIO_NOPULL;
    g.Speed = GPIO_SPEED_FREQ_LOW;
    HAL_GPIO_Init(GPIOI, &g);

    while (1) {
        HAL_GPIO_WritePin(GPIOI, GPIO_PIN_1, GPIO_PIN_SET);
        HAL_Delay(500);
        HAL_GPIO_WritePin(GPIOI, GPIO_PIN_1, GPIO_PIN_RESET);
        HAL_Delay(500);
    }
}

Press Run. The onboard LD1 LED (connected to PI1) will blink at 1 Hz.

3. Code Style: main() and while(1)

Unlike Arduino sketches, the STM32 uses the standard ARM C entry point:

int main() {
    // One-time initialization here
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();

    while (1) {
        // Repeated code here (the "loop")
        HAL_GPIO_TogglePin(GPIOI, GPIO_PIN_1);
        HAL_Delay(500);
    }
}

The transpiler automatically splits this into setup() (code before while(1)) and loop() (body of while(1)).

4. GPIO Programming

HAL Method (Recommended)

__HAL_RCC_GPIOx_CLK_ENABLE();  // Enable clock for port x

GPIO_InitTypeDef g = {0};
g.Pin = GPIO_PIN_n;
g.Mode = GPIO_MODE_OUTPUT_PP;   // Push-pull output
g.Pull = GPIO_NOPULL;
g.Speed = GPIO_SPEED_FREQ_LOW;
HAL_GPIO_Init(GPIOx, &g);

HAL_GPIO_WritePin(GPIOx, GPIO_PIN_n, GPIO_PIN_SET);    // HIGH
HAL_GPIO_WritePin(GPIOx, GPIO_PIN_n, GPIO_PIN_RESET);  // LOW
HAL_GPIO_TogglePin(GPIOx, GPIO_PIN_n);
uint8_t val = HAL_GPIO_ReadPin(GPIOx, GPIO_PIN_n);

Direct Register Method

// Set PI1 as output: MODER1 = 01
GPIOI->MODER |= (1 << 2);   // bits [3:2] = 01

// Write HIGH to PI1
GPIOI->BSRR = GPIO_PIN_1;    // set bit

// Write LOW to PI1
GPIOI->BSRR = GPIO_PIN_1 << 16;  // reset bit

// Read PI1
uint32_t val = GPIOI->IDR & GPIO_PIN_1;
Note: When using direct register access, you must enable the GPIO clock first via RCC->AHB1ENR.

5. Onboard LED (LD1)

The onboard user LED LD1 is connected to PI1 (mapped to board pin D13).

__HAL_RCC_GPIOI_CLK_ENABLE();
// Configure PI1 as output
GPIOI->MODER |= (1 << 2);

while (1) {
    GPIOI->BSRR = (1 << 1);    // LED ON
    HAL_Delay(500);
    GPIOI->BSRR = (1 << 17);   // LED OFF (bit 16+1)
    HAL_Delay(500);
}

6. User Button (B1)

The blue user button B1 is connected to PC13.

__HAL_RCC_GPIOC_CLK_ENABLE();
GPIO_InitTypeDef g = {0};
g.Pin = GPIO_PIN_13;
g.Mode = GPIO_MODE_INPUT;
g.Pull = GPIO_PULLUP;
HAL_GPIO_Init(GPIOC, &g);

if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET) {
    // Button pressed (active low)
}

7. ADC (Analog-to-Digital Converter)

6 analog input pins: A0 (PA0), A1 (PA4), A2 (PA5), A3 (PA6), A4 (PA7), A5 (PC4).

// Read analog value from A0 (PA0)
ADC_HandleTypeDef hadc1;
hadc1.Instance = ADC1;
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
uint32_t raw = HAL_ADC_GetValue(&hadc1);
float voltage = raw * 3.3f / 4095.0f;  // 12-bit ADC, 3.3V ref

8. UART Serial Communication

// USART1: TX=PA9, RX=PA10
UART_HandleTypeDef huart1;
huart1.Instance = USART1;
huart1.Init.BaudRate = 115200;
huart1.Init.WordLength = UART_WORDLENGTH_8B;
huart1.Init.StopBits = UART_STOPBITS_1;
huart1.Init.Parity = UART_PARITY_NONE;
HAL_UART_Init(&huart1);

char msg[] = "Hello STM32!\r\n";
HAL_UART_Transmit(&huart1, (uint8_t*)msg, sizeof(msg)-1, 100);

uint8_t rx;
HAL_UART_Receive(&huart1, &rx, 1, 100);

9. Timers

The board has 14 timers (TIM1–TIM14). Basic PWM example:

TIM_HandleTypeDef htim2;
htim2.Instance = TIM2;
htim2.Init.Prescaler = 10800 - 1;   // 108 MHz / 10800 = 10 kHz
htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
htim2.Init.Period = 1000 - 1;       // 10 Hz
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);

10. SPI

SPI_HandleTypeDef hspi1;
hspi1.Instance = SPI1;
hspi1.Init.Mode = SPI_MODE_MASTER;
hspi1.Init.CLKPolarity = SPI_POLARITY_HIGH;
hspi1.Init.CLKPhase = SPI_PHASE_2EDGE;
HAL_SPI_Init(&hspi1);

uint8_t tx[] = {0x01, 0x02, 0x03};
HAL_SPI_Transmit(&hspi1, tx, 3, 100);

uint8_t rx[3];
HAL_SPI_Receive(&hspi1, rx, 3, 100);

14. Tips & Gotchas

Tip: Always enable the GPIO clock before configuring pins. Use __HAL_RCC_GPIOx_CLK_ENABLE() or set the bit in RCC->AHB1ENR.
Tip: Use BSRR for atomic pin writes instead of ODR to avoid read-modify-write race conditions.
Tip: The simulator auto-converts your C code into async JavaScript. Use HAL_Delay() or delay_ms() for timing — bare loops won't work as expected.
Warning: All GPIO pins operate at 3.3V logic. The simulator clamps outputs to 3.3V max.
Warning: The TFT LCD is not directly controlled through GPIO in the simulator. Use the component panel to add a TFT display component separately.
