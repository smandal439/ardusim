LPC2148 Programming Guide

Board: LPC2148 SmartX Board  |  MCU: NXP LPC2148 ARM7TDMI-S 60MHz  |  Logic: 3.3V

This guide covers how to write C code for the LPC2148 in the ArduSim simulator using real register-level programming, just like on physical hardware.

1. Board Overview

The LPC2148 SmartX Board in ArduSim replicates the real NXP LPC2148 ARM7 microcontroller with:

  • MCU: ARM7TDMI-S, 60 MHz, 512 KB Flash, 40 KB SRAM
  • GPIO: Port 0 (P0.0–P0.23, P0.25–P0.28) and Port 1 (P1.16–P1.31)
  • Onboard LEDs: LED1 (P0.12, red), LED2 (P0.13, green), LED3 (P0.14, orange), LED4 (P0.15, blue)
  • ADC: 10-bit, 8 channels on P0.26–P0.28 (AIN0–AIN2)
  • UART0: TXD0 (P0.2), RXD0 (P0.3)
  • UART1: TXD1 (P0.4), RXD1 (P0.5)
  • SPI0: SCK0 (P0.7), MISO0 (P0.8), MOSI0 (P0.9), SSEL0 (P0.10)
  • I2C0: SDA0, SCL0
  • Timers: Timer0 and Timer1
  • DAC: 10-bit, output on P0.25 (AOUT)
  • Logic Level: 3.3V (outputs are clamped to 3.3V max)
  • Power: VCC (3.3V), VBUS (5V), GND
Note: All I/O pins operate at 3.3V logic levels. Connecting 5V signals directly may cause issues in real hardware. In the simulator, logic HIGH is 3.3V.

2. Quick Start

Open ArduSim, select LPC2148 SmartX Board from the board selector, and write code in the editor:

#include <LPC214x.h>

int main() {
    IO0DIR |= (1 << 12);           // P0.12 = output (LED1)
    while (1) {
        IO0SET = (1 << 12);       // LED1 ON
        delay_ms(500);
        IO0CLR = (1 << 12);       // LED1 OFF
        delay_ms(500);
    }
}

Press Run. The red LED1 on the board will blink at 1 Hz.

Tip: The simulator automatically converts your int main() + while(1) pattern into the internal setup() + loop() format. You write standard LPC2148 C code — no need to use Arduino-style functions.

3. Code Style: main() and while(1)

Unlike Arduino sketches, the LPC2148 uses the standard ARM7 C entry point:

int main() {
    // One-time initialization here
    IO0DIR |= (1 << 12);   // Set P0.12 as output

    while (1) {
        // Repeated code here (the "loop")
        IO0SET = (1 << 12);
        delay_ms(500);
        IO0CLR = (1 << 12);
        delay_ms(500);
    }
}

The transpiler automatically splits this into:

  • async function setup() — runs once (code before while(1))
  • async function loop() — runs repeatedly (code inside while(1))

If you declare variables before while(1), they are promoted to outer scope so they persist between loop iterations:

int main() {
    int count = 0;                  // This variable persists across loop() calls
    IO0DIR |= (0xF << 12);         // P0.12-P0.15 as outputs
    while (1) {
        IO0CLR = 0xF << 12;        // Clear all 4 LEDs
        IO0SET = (count & 0xF) << 12; // Show count on LEDs
        delay_ms(500);
        count = (count + 1) & 0xF;
    }
}
Important: The simulator supports int main() and int main(void). If you use void setup() + void loop() style, the auto-conversion is skipped and Arduino-style runs directly.

4. GPIO Programming

GPIO is controlled through memory-mapped registers. The simulator intercepts register writes and updates the visual pin states on the canvas.

Direction Register (IO0DIR / IO1DIR)

Set a pin as output (1) or input (0):

IO0DIR |= (1 << 12);      // P0.12 = output
IO0DIR &= ~(1 << 16);     // P0.16 = input

Writing Outputs

IO0SET = (1 << 12);       // Set P0.12 HIGH (LED ON)
IO0CLR = (1 << 12);       // Set P0.12 LOW  (LED OFF)

You can also write directly to IO0PIN:

IO0PIN = (1 << 12);       // P0.12 HIGH, all other P0.x LOW

Reading Inputs

if (IO0PIN & (1 << 16)) {
    // P0.16 is HIGH
} else {
    // P0.16 is LOW
}

Bitwise Operations

All compound assignments are supported on register names:

IO0DIR |= (1 << 12);      // Set bit
IO0DIR &= ~(1 << 12);     // Clear bit
IO0DIR ^= (1 << 12);      // Toggle bit
IO0DIR <<= 2;              // Left shift
IO0DIR >>= 1;              // Right shift

Port 1 (P1.16 – P1.31)

IO1DIR |= (1 << 16);      // P1.16 = output
IO1SET = (1 << 16);       // P1.16 HIGH
IO1CLR = (1 << 16);       // P1.16 LOW
if (IO1PIN & (1 << 16)) { // Read P1.16
    // HIGH
}
Note: Port 1 only has P1.16–P1.31 accessible on the SmartX board. Bits 0–15 of IO1PIN are read from internal register state.

5. Onboard LEDs

The SmartX board has 4 user LEDs directly connected to GPIO pins:

LEDPinColorBitmask
LED1P0.12Red(1 << 12)
LED2P0.13Green(1 << 13)
LED3P0.14Orange(1 << 14)
LED4P0.15Blue(1 << 15)

You can also use the predefined constants:

IO0DIR |= (1 << LED1);    // Same as (1 << 12)
IO0SET = (1 << LED1);     // LED1 ON

Blink all 4 LEDs in sequence:

#include <LPC214x.h>

int main() {
    IO0DIR |= (0xF << 12);       // P0.12-P0.15 = outputs
    while (1) {
        IO0SET = (1 << LED1);    // LED1 ON
        delay_ms(200);
        IO0CLR = (1 << LED1);    // LED1 OFF
        IO0SET = (1 << LED2);    // LED2 ON
        delay_ms(200);
        IO0CLR = (1 << LED2);    // LED2 OFF
        IO0SET = (1 << LED3);    // LED3 ON
        delay_ms(200);
        IO0CLR = (1 << LED3);    // LED3 OFF
        IO0SET = (1 << LED4);    // LED4 ON
        delay_ms(200);
        IO0CLR = (1 << LED4);    // LED4 OFF
    }
}
Tip: You can also use the alias LED_BUILTIN which maps to pin 12 (LED1).

6. Reading Buttons / Digital Input

To read a push button, configure the pin as input and read IO0PIN:

#include <LPC214x.h>

int main() {
    IO0DIR |= (1 << 12);        // P0.12 = output (LED1)
    IO0DIR &= ~(1 << 16);       // P0.16 = input  (button)
    while (1) {
        if (!(IO0PIN & (1 << 16))) {  // Button active LOW
            IO0SET = (1 << 12);        // LED1 ON
        } else {
            IO0CLR = (1 << 12);        // LED1 OFF
        }
        delay_ms(50);
    }
}
Wiring: Connect one side of the push button to the GPIO pin (e.g., P0.16) and the other side to GND. The button reads LOW when pressed (active-low). No external pull-up resistor is needed in the simulator — the pin reads the wire state directly.

7. ADC (Analog-to-Digital Converter)

The LPC2148 has a 10-bit ADC with 8 channels. In the simulator, channels are mapped to analog-capable pins:

ChannelPinRegister
AIN0P0.26AD0DR0
AIN1P0.27AD0DR1
AIN2P0.28AD0DR2

Reading ADC

#include <LPC214x.h>

int main(void) {
    // Setup UART0 for serial output
    PINSEL0 |= (1 << 0) | (1 << 2);   // P0.2=TXD0, P0.3=RXD0
    U0LCR = 0x83;                        // 8N1, DLAB=1
    U0DLL = 0x06;                        // 9600 baud @ 60MHz PCLK
    U0DLM = 0x00;
    U0LCR = 0x03;                        // DLAB=0, 8N1

    // Setup ADC: PDN=1, channel 0 (AIN0 = P0.26)
    AD0CR = (1 << 21) | (1 << 0);

    while (1) {
        AD0CR |= (1 << 24);            // Start conversion
        while (!(AD0GDR & (1 << 31))); // Wait for DONE bit
        int val = (AD0GDR >> 6) & 0x3FF; // Extract 10-bit result

        // Send value over UART0
        uart0_printNum(val);
        uart0_print("\r\n");

        AD0CR &= ~(1 << 24);           // Stop
        delay_ms(500);
    }
}

ADC Bit Layout

RegisterBitsPurpose
AD0CR[21]PDN — Power on ADC (must be 1)
AD0CR[24]START — Begin conversion
AD0CR[16]BURST — Continuous mode
AD0CR[3:0]Channel select (0–7)
AD0GDR[31]DONE — Conversion complete
AD0GDR[15:6]10-bit ADC result
Tip: Use the alias A0 for pin 26 (AIN0), A1 for pin 27 (AIN1), and A2 for pin 28 (AIN2).

DAC (Digital-to-Analog Converter)

The LPC2148 has a 10-bit DAC on P0.25 (AOUT). Write a 10-bit value to the DACR register:

// Output analog value on P0.25
DACR = (value & 0x3FF) << 6;   // Write 10-bit DAC value

8. UART Serial Communication

UART0 is fully simulated. Write characters to the Serial Monitor panel.

UART0 Initialization

// Configure P0.2 as TXD0, P0.3 as RXD0
PINSEL0 |= (1 << 0) | (1 << 2);

// 8N1, DLAB=1 (to access divisor latches)
U0LCR = 0x83;

// Set baud rate: 9600 baud at 60 MHz PCLK
// Divider = 60000000 / (16 * 9600) = 390.625 ≈ 0x186
// For simplicity: U0DLL=0x06, U0DLM=0x00 gives ~57600 baud
U0DLL = 0x06;
U0DLM = 0x00;

// DLAB=0, 8N1
U0LCR = 0x03;

UART0 Transmit

void uart0_tx(char c) {
    while (!(U0LSR & 0x20));   // Wait for THR empty (bit 5)
    U0THR = c;                  // Send character
}

void uart0_print(const char *s) {
    while (*s) uart0_tx(*s++);
}

UART0 Receive

// Check if data is available
if (U0LSR & 0x01) {           // Data Ready (bit 0)
    char c = U0RBR;             // Read received byte
}

11. Timing & Delay Functions

Two delay functions are available and map to the real LPC2148 firmware library:

delay_ms(500);             // Wait 500 milliseconds
delay_us(100);             // Wait 100 microseconds

Both are async internally, so they yield to the simulator without blocking the browser. They advance the simulation clock by the specified time.

Note: delay_ms() and delay_us() use await internally. You can call them directly in your C code — the transpiler handles the conversion automatically.

12. Tips & Gotchas

Compiler Directives

The #include <LPC214x.h> directive is recognized by the simulator's plugin system. While the header content is stripped (the constants are injected directly), you should still include it so the LPC2148 plugin activates:

#include <LPC214x.h>    // Required! Activates the LPC2148 plugin

Available C Constructs

The transpiler supports standard C constructs:

  • int, char, unsigned int, long, short, byte, float, double
  • if / else, for, while, do...while
  • switch / case
  • function declarations (become async function)
  • char[] string arrays
  • C-style casts: (unsigned long)expr

What NOT to Use

  • pinMode(), digitalWrite(), digitalRead() — these are Arduino functions, not ARM7. Use register-level GPIO instead.
  • analogRead(), analogWrite() — use AD0CR/AD0GDR for ADC and DACR for DAC.
  • Serial.begin(), Serial.print() — use direct UART register access (U0THR, U0LSR).
  • millis(), micros() — use Timer0/Timer1 registers (T0TC) for timing.

Serial Monitor Output

When using UART0 transmit, characters appear in the Serial Monitor panel. Make sure the Serial Monitor is open and the baud rate is set (default 9600).

Simulation Speed

The simulator runs in real-time by default. delay_ms(500) pauses for 500ms of simulation time. The simulation clock advances by the delay duration. For tight loops without delays, the simulator yields periodically to keep the UI responsive.

Wiring on the Canvas

Drag the LPC2148 board from the Boards category in the component library. Connect wires between board pins and other components by clicking a pin on one component and dragging to a pin on another.
